# 10. Контроль доступа: турникет и считыватель

[← Организации](09-organizations.md) · [Оглавление](README.md) · [Далее: Подделки →](11-forgery.md)

Оба блока выдают **сигнал редстоуна**, когда проход разрешён. К ним можно подключить двери, поршни, ворота.

## Турникет

Рецепт: ` R ` / ` I ` / `III` — редстоун и железо.

Пропускает **только по билетам**. Подойдите и нажмите **ПКМ** с билетом в руке.

**Настройки** (Shift + ПКМ пустой рукой, владелец):

| Параметр | Значение |
|---|---|
| Название | Пишется в отметке на билете |
| Фильтр | Слова через запятую. Билет подойдёт, если в названии шаблона, организации или ID есть хоть одно из них. Пусто — подходит любой билет |
| Режим | **Компостировать** (один проход по билету) · **Забирать билет** · **Только проверять** |
| Сигнал | 1–10 секунд |
| Замок и допущенные | Как у всех блоков |

Турникет отказывает, если билет недействителен (отозван, подделан, его нет в реестре), уже прокомпостирован или не подходит под фильтр.

## Считыватель документов

Рецепт: `IGI` / `IRI` / `IPI` — железо, стеклянная панель, редстоун, бумага.

Принимает **паспорта, удостоверения, билеты и документы** (например, пропуска). Ведёт **журнал** последних 12 проходов.

**Настройки:**

| Параметр | Значение |
|---|---|
| Принимает | Флажки: Паспорта / Удостоверения / Билеты / Документы и пропуска |
| Фильтр | Слова через запятую — ищутся в шаблоне, организации, номере, держателе, теме |
| **Зона** | Например `Склад`. Пройдёт только **документ**, у которого во вкладке «Реквизиты» указана эта зона |
| Только держатель | Документ должен быть выдан тому, кто его прикладывает (включено по умолчанию) |
| Режим | **Только проверять** · **Компостировать (один раз)** · **Забирать документ** |
| Сигнал | 1–30 секунд |

**Причины отказа:** документ недействителен, истёк срок, выдан другому человеку, нет допуска в зону, это копия (нужен оригинал), это черновик, вид документа не принимается, не подходит под фильтр.

## Пример: пропуск на склад

1. Мэрия выпускает документ по шаблону **ПРОПУСК**. Во вкладке «Реквизиты» указаны держатель `Alex`, зона `Склад` и срок действия.
2. У двери склада стоит считыватель: принимает «Документы и пропуска», зона — `Склад`, режим — «Только проверять».
3. Alex прикладывает пропуск, считыватель даёт сигнал, и дверь открывается. Чужой, просроченный или отозванный пропуск не сработает.
