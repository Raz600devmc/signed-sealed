# 2. Документы

[← Быстрый старт](01-quick-start.md) · [Оглавление](README.md) · [Далее: Подписи →](03-signatures.md)

## Бланк

**Бланк документа** крафтится из бумаги и чернильного мешка. Чистый бланк можно заполнить сколько угодно раз, пока он не выпущен. Нажмите им **ПКМ**, чтобы открыть редактор.

## Редактор документа

Редактор разделён на две вкладки.

### Вкладка «Документ»

| Поле | Что писать | Лимит |
|---|---|---|
| **Тип** | Переключается стрелками ◀ ▶ | — |
| **Номер** | Внутренний номер, например `42/2026` | 20 символов |
| **Ваша должность** | «Мэр», «Начальник полиции»… | 60 |
| **Организация** | Кто выпускает документ | 80 |
| **Тема** | О чём документ | 140 |
| **Текст документа** | Сам текст | 2400 |

**Типы документов:**

- **Свободный документ** — без шапки, оформляете как хотите.
- **Постановление, Приказ, Справка, Договор, Пропуск** — встроенные шаблоны с заголовком и оформлением.
- **Шаблоны организаций** — свои бланки с гербом, цветами и готовым текстом (см. [Организации и шаблоны](09-organizations.md)).

Черновик сохраняется автоматически: можно закрыть редактор и вернуться позже.

### Вкладка «Реквизиты»

Если хоть одно поле здесь заполнено, на вкладке появится точка `•`.

| Поле | Что делает |
|---|---|
| **Ссылается на (рег. №)** | Указывает связанные документы, например `RD-000012`. Видно в реестре и на документе. |
| **Отменяет (рег. №)** | Этот документ **заменяет** старый. После выпуска старый в реестре помечается как «заменён» и перестаёт проходить проверку. Заменять можно только свои документы или документы своей организации. |
| **Действует до** | Реальная дата `дд.мм.гггг`. После неё документ считается **просроченным** везде: при проверке, в реестре и на считывателях. |
| **Кому выдан** | Ник владельца. Считыватель пропустит только этого игрока. |
| **Зоны** | Через запятую: `Депо, Стройка-1`. Считыватель с такой зоной примет пропуск. |
| **Публичный / Закрытый в реестре** | По умолчанию документ **закрытый**: посторонние в реестре видят только статус, тип и дату. Публичный показывает подробности всем. |

## Выпуск

Нажмите **«Подписать и выпустить»**, нарисуйте подпись — и документ:

- получает **регистрационный номер** `RD-xxxxxx`;
- записывается в реестр сервера с цифровой подписью;
- больше **не редактируется** (менять текст выпущенного документа нельзя — только выпустить новый, который его «отменяет»).

На документ можно поставить **до 4 подписей** и **до 6 печатей**. Как добавить подписи других людей — в разделе [Подписи](03-signatures.md).

## Что можно делать с выпущенным документом

| Действие | Как |
|---|---|
| Прочитать | ПКМ документом |
| Рассмотреть вблизи | Клавиша **V** (см. [Проверка](11-forgery.md)) |
| Проверить подлинность | Документ в руке → `/seal verify` |
| Показать другому игроку | `/seal show <игрок>` — у него откроется ваш документ |
| Поставить печать | Печать в основной руке, документ во второй → ПКМ |
| Снять копию | [Принтер](08-office.md#принтер) — на копии пометка «КОПИЯ» |
| Отправить | В [конверте](06-mail.md) или через [Входящие компьютера](08-office.md#входящие) |
| Повесить на доску | [Доска объявлений](07-newspapers.md#доска-объявлений) |
| Отозвать | Документ в руке → `/seal revoke` (автор или администрация) |
| Уничтожить | [Шредер](08-office.md#шредер) — документ аннулируется в реестре |

## Статусы документа

| Статус | Что значит |
|---|---|
| ✅ **Подлинный** | Есть в реестре, подпись сервера верна |
| 📄 **Копия** | Сделан на принтере, оригиналом не является |
| 🔁 **Заменён** | Выпущен документ, который его отменяет |
| ⛔ **Отозван** | Отозван автором или администрацией |
| ⌛ **Истёк** | Прошла дата «Действует до» |
| ❌ **Подделка** | Нет в реестре или данные не совпадают с реестром |
