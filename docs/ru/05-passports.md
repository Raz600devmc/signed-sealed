# 5. Паспорта, удостоверения, билеты и штрафы

[← Печати](04-stamps.md) · [Оглавление](README.md) · [Далее: Почта →](06-mail.md)

Все четыре вида — это **бланки по шаблону**. Шаблон рисует администрация (или организация), а игроки получают пустые бланки и заполняют их сами.

| Формат | Для чего |
|---|---|
| **Паспорт** | Книжка с разворотами, фото, гербом и страницами для виз и погранштампов |
| **Удостоверение** | Карточка: служебное удостоверение, права, пропуск сотрудника |
| **Билет** | Проезд, вход на мероприятие. Проходит через [турникет](10-access.md#турникет) и [считыватель](10-access.md#считыватель-документов) |
| **Штраф** | Квитанция о штрафе |

## Шаблоны

### Создать шаблон (администрация)
1. `/seal passport designer` — пустой конструктор, или `/seal passport designer <страна>` — готовый шаблон страны.
2. Доступны пресеты: Германия, Франция, Италия, Испания, Польша, Великобритания, Нидерланды, Швеция, Норвегия, Финляндия, Украина, Чехия, Греция, Португалия, Швейцария, Австрия, Турция.
3. В конструкторе настраиваются: формат, цвета, герб, надписи, **поля** (имя, дата рождения, номер, любые свои), их расположение, обязательность и подсказки, место под фото.
4. Шаблон отправляется на одобрение.

### Управление шаблонами

| Команда | Что делает |
|---|---|
| `/seal passport list` · `list pending` | Все шаблоны / ожидающие одобрения |
| `/seal passport approve <шаблон>` | Одобрить |
| `/seal passport edit <шаблон>` | Открыть шаблон в конструкторе |
| `/seal passport preset <страна>` | Сразу установить и одобрить шаблон страны |
| `/seal passport revoke <шаблон>` | Отозвать: новые бланки по нему больше не оформляются |
| `/seal passport delete <шаблон>` | Удалить из реестра |

## Выдача бланков

- Администрация: `/seal passport give <шаблон> <игроки>` — игроки получают **пустые бланки**.
- Организация или администрация может **печатать бланки на принтере**: на каждый бланк паспорта нужна **книга**, на остальные — **лист бумаги** (см. [Принтер](08-office.md#принтер)).

## Заполнение

1. Возьмите пустой бланк и нажмите **ПКМ**.
2. Заполните поля. Обязательные помечены.
3. **Сфотографируйтесь** — фото делается с вашего персонажа.
4. **Подпишите** — нарисуйте подпись.
5. Документ выпущен и записан в реестр.

Право заполнять бланки — `signedsealed.passport.fill` (по умолчанию у всех).

## Использование

| Действие | Как |
|---|---|
| Открыть | ПКМ |
| Показать другому игроку | `/seal show <игрок>` |
| Проверить | `/seal verify` с паспортом в руке |
| Поставить визу или погранштамп | Печать вида «Виза» / «Погранштамп» — так же, как обычную печать |
| Отозвать (админ) | Паспорт в руке → `/seal passport revoke` |
| Пройти турникет / считыватель | ПКМ по блоку с билетом или удостоверением в руке |

У использованного билета появляется отметка **«Прокомпостирован»** — повторно по нему не пройти.
