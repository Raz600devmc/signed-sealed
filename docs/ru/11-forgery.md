# 11. Подделки и проверка подлинности

[← Контроль доступа](10-access.md) · [Оглавление](README.md) · [Далее: Администрирование →](12-admin.md)

Подделки — часть игры: шпионы, контрабандисты, мошенники. Мод даёт их делать, но у властей есть способы такие документы поймать.

## Набор фальсификатора

Рецепт: `FIP` / `LLL` — перо, чернильный мешок, бумага, кожа.

1. Возьмите **подлинный выпущенный** документ, паспорт, удостоверение, билет или штраф **во вторую руку**.
2. Нажмите **ПКМ** набором.
3. Измените нужные данные: номер, должность, организацию, тему, текст. Для паспорта можно вставить другое фото (ссылкой или файлом).
4. Нажмите **«Сделать подделку»**. Расход: **лист бумаги** для документа, **книга** для паспорта.

### Поддельная печать
В том же окне, в разделе «Печати на документе», выберите оттиск и создайте **поддельную печать** этой организации. Расход — **железный слиток**. Такой печатью можно ставить оттиски, но проверка распознает их как фальшивые.

Право — `signedsealed.forge` (по умолчанию у всех; на серьёзных RP-серверах его часто выдают только «криминальным» ролям).

## Как поймать подделку

Подделку не отличить на глаз, но её выдаёт:

| Способ | Как |
|---|---|
| **Проверка по реестру** | `/seal verify` с документом в руке, кнопка «Проверить подлинность» в просмотре или [считыватель](10-access.md#считыватель-документов). Данные сверяются с записью в реестре |
| **УФ-свет** | Кнопка «УФ-свет» в окне документа. Подлинник показывает скрытые защитные знаки |
| **Лупа** | Кнопка «Лупа» — микротекст и мелкие детали |
| **Код защиты** | Уникальный код на подлиннике, который сверяется с реестром |
| **Осмотр (клавиша V)** | 3D-осмотр документа в руке: мышь — вращать, колесо — приблизить, пробел/ПКМ — открыть или перевернуть |

## Статусы при проверке

| Статус | Что значит |
|---|---|
| **Подлинный** | Совпадает с реестром |
| **Подделка** | Данные или оттиск не совпадают с реестром |
| **Отозван** / **Аннулирован** | Был действителен, но отозван администрацией или уничтожен в шредере |
| **Нет в реестре** | Документ не с этого сервера |
| **Копия** | Заверенная копия, не оригинал |
| **Черновик** | Документ не выпущен, силы не имеет |
| **Устаревшая версия** | После этого экземпляра на документ добавили подпись или печать — действительна только актуальная версия |
| **Истёк срок** | Срок действия из «Реквизитов» прошёл |
