## Шпаргалка

| Действие | Как |
|---|---|
| Заполнить бланк | ПКМ бланком документа |
| Поставить печать | Печать в основной руке, документ во второй → ПКМ |
| Проверить документ | Документ в руке → `/seal verify` |
| Рассмотреть вблизи (УФ, лупа) | Клавиша **V** |
| Показать документ игроку | `/seal show <игрок>` |
| Панель администратора | Клавиша **K** или `/seal admin` |
| Настроить блок (турникет, считыватель, сканер) | Shift + ПКМ пустой рукой (только владелец) |
| Сделать бэкап ключа | `/seal backup` |
