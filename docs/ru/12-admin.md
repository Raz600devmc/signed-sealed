# 12. Администрирование сервера

[← Подделки](11-forgery.md) · [Оглавление](README.md) · [Далее: Рецепты и FAQ →](13-faq.md)

## Панель администратора

Клавиша **K** или `/seal admin`. Вкладки:

| Вкладка | Что там |
|---|---|
| **Печати** | Эскизы печатей на одобрении, выдача, отзыв |
| **Шаблоны** | Шаблоны паспортов, удостоверений, билетов и штрафов на одобрении |
| **Реестр** | Поиск по всем выпущенным документам и паспортам, отзыв |

Цифра на вкладке — сколько заявок ждёт решения.

## Типичный порядок запуска RP-сервера

1. Поставьте мод на сервер и всем игрокам (версии должны совпадать, иначе сервер не пустит клиента).
2. Установите шаблоны паспортов: `/seal passport preset <страна>` или нарисуйте свой в `/seal passport designer`.
3. Создайте организации (мэрия, полиция) и назначьте руководителей — `/seal org`.
4. Одобрите или выдайте печати организациям: `/seal stamp list pending` → `approve` → `give`.
5. Выдайте бланки паспортов (`/seal passport give`) или позвольте мэрии печатать их на принтере.
6. При необходимости ограничьте права через LuckPerms (см. ниже).

## Права (permissions)

Мод использует стандартный Permission API, поэтому права настраиваются в **LuckPerms** и аналогах. Все узлы начинаются с `signedsealed.`

| Узел | По умолчанию | Что разрешает |
|---|---|---|
| `document.create` | все | Создавать документы |
| `document.sign` | все | Подписывать |
| `document.verify` | все | Проверять подлинность |
| `document.template` | все | Создавать свои шаблоны документов |
| `stamp.apply` | все | Ставить печати |
| `stamp.design` | все | Рисовать эскизы печатей |
| `stamp.issue` | OP | Одобрять и выдавать печати |
| `passport.fill` | все | Заполнять бланки |
| `passport.issue` | OP | Шаблоны паспортов, выдача бланков |
| `show` | все | `/seal show` |
| `forge` | все | Набор фальсификатора |
| `print` | все | Принтер, архив, папки |
| `newspaper.publish` | все | Выпускать газеты |
| `mail.send` | все | Отправлять письма |
| `mail.mass` | OP | Массовые рассылки |
| `archive.scan` | все | Сканер |
| `org.create` | все | Создавать организации |
| `admin` | OP | Всё: панель K, отзыв, удаление, обход замков |

«OP» — уровень оператора 2 и выше.

Пример LuckPerms — подделывать документы могут только игроки группы `criminal`:
```
/lp group default permission set signedsealed.forge false
/lp group criminal permission set signedsealed.forge true
```

## Отзыв и удаление

| Команда | Действие |
|---|---|
| `/seal revoke` | Отозвать документ в руке |
| `/seal passport revoke` | Отозвать паспорт в руке |
| `/seal stamp revoke <id>` · `delete <id>` | Отозвать или удалить печать |
| `/seal passport revoke <шаблон>` · `delete <шаблон>` | Отозвать или удалить шаблон |
| `/seal paper revoke` · `restore` | Отозвать или вернуть выпуск газеты |

Отозванный документ остаётся у игрока, но при любой проверке показывает **«Отозван»**.

## Данные и резервные копии

- Реестр — `<мир>/data/signedsealed.dat`, организации/почта/блоки — `<мир>/data/signedsealed_office.dat`.
- Картинки (фото, логотипы, печати, вёрстка газет) — в папке `<мир>/signedsealed/`. Её автобэкап **не** копирует (она большая) — включите её в свои обычные бэкапы мира.
- **Автобэкап** (с версии 2.5.1):
  - копии кладутся в `<мир>/signedsealed_backups/<дата>_<причина>/`;
  - делаются при запуске, при остановке и каждые 30 минут вместе с сохранением мира;
  - хранятся последние 20 копий.
- `/seal backup` (уровень 3) — сделать копию прямо сейчас.
- **Автовосстановление:** если при запуске `signedsealed.dat` пропал, мод сам возьмёт последнюю копию и напишет об этом в лог.
- **Ручное восстановление:** остановите сервер, скопируйте оба `.dat` из нужной папки бэкапа в `<мир>/data/` и запустите сервер.

## Производительность

- Картинки по ссылкам скачивает **только клиент автора** при загрузке, и они проверяются по размеру. Остальные игроки получают картинку с сервера, их IP никуда не уходят.
- Доски объявлений с лентой газеты опрашивают реестр не чаще раза в 5 секунд на издание.
- Документы не тикают: нагрузки в мире нет, пока с ними не работают.
