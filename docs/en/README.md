## Cheat sheet

| Action | How |
|---|---|
| Fill in a form | Right-click with a Document Form |
| Place a stamp | Stamp in main hand, document in off hand → right-click |
| Verify a document | Document in hand → `/seal verify` |
| Look closely (UV, magnifier) | **V** key |
| Show a document to a player | `/seal show <player>` |
| Admin panel | **K** key or `/seal admin` |
| Configure a block (gate, reader, scanner) | Shift + right-click with an empty hand (owner only) |
| Back up the registry now | `/seal backup` |

> Commands also work as `/signedsealed …`. The in-game UI follows your Minecraft language (English, Russian, German).
