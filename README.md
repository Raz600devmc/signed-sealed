# Signed & Sealed

In-game documents, stamps, hand-drawn signatures, and passports with visas, border stamps, security marks, and authenticity checks for roleplay servers.

## Features
- Passports, ID cards, tickets, and fines.
- Newspapers with a full layout editor.
- Letters with wax seals and offline mailboxes.
- Advanced anti-forgery mechanics (UV light, magnifier, NBT protection).

## Project Structure
This repository contains source code for both loaders:
- `forge-proj` — Source code for Forge (1.20.1)
- `neo-proj` — Source code for NeoForge (1.21.1)
