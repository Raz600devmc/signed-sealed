# Signed & Sealed

In-game documents, stamps, hand-drawn signatures, and passports with visas, border stamps, security marks, and authenticity checks for roleplay servers.

## Features
- Passports, ID cards, tickets, and fines.
- Newspapers with a full layout editor.
- Letters with wax seals and offline mailboxes.
- Advanced anti-forgery mechanics (UV light, magnifier, NBT protection).
- Organizations, mailing lists, newspaper subscriptions, document templates, remote signature requests and registry numbers (2.4).
- Document readers with redstone output, temporary passes with expiry dates and zones, registry search, computer inbox, a new computer desktop and notice boards (2.5).

## Current version
**2.5.0** — Forge 1.20.1 and NeoForge 1.21.1. Client and server must run the same version.

## Building
- NeoForge: `cd neo-proj && ./gradlew build` (Java 21)
- Forge: `cd forge-proj && ./gradlew build` (Java 17)

## Project Structure
This repository contains source code for both loaders:
- `forge-proj` — Source code for Forge (1.20.1)
- `neo-proj` — Source code for NeoForge (1.21.1)
